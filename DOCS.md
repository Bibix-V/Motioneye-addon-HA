# Home Assistant Community Add-on: motionEye

Simple, elegant and feature-rich CCTV/NVR for your cameras.

## Install the add-on

1. Install `motionEye` from this repository's add-on store.
2. Set up your cameras in the `motionEye` configuration.
3. Start the add-on.

## How to use

Read the [documentation](https://github.com/motioneye-project/motioneye) for more information.

## Support
