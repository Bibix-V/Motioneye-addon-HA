# motionEye Addon for Home Assistant

Simple, elegant and feature-rich CCTV/NVR for your cameras.

## About

motionEye is a web-based interface for Motion, the popular video surveillance software. It allows you to monitor your cameras from anywhere, record video, and receive alerts.

## Features

- Support for multiple cameras (USB, IP)
- MJPEG streaming
- Video recording
- Motion detection
- Web interface
- REST API

## Configuration

The addon uses the `/share` folder for configuration and storage. Your camera configurations are stored in `/share/motioneye/`.
